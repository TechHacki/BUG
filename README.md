## 🚀 About BUG

BUG is a compact, multi-platform hardware tool designed for makers, developers, and security enthusiasts.  
It combines a powerful microcontroller, interactive display, wireless connectivity, and expandable hardware into a single portable device.

Built for flexibility, BUG supports **STM32, ESP32, and RP2040**, allowing users to choose the platform that best fits their workflow — whether it's high performance, wireless capabilities, or rapid prototyping.

From IoT development and automation to ethical hacking and hardware experimentation, BUG provides a seamless experience with ready-to-use firmware, modular design, and an intuitive user interface.

Whether you're building tools, testing systems, or creating new ideas, BUG is designed to be your all-in-one development companion.


## ✨ Features

### 🧠 Multi-Platform Support
- Compatible with **STM32, ESP32, and RP2040**
- Choose performance, wireless, or flexibility based on your needs

---

### 📺 Integrated TFT Display
- ST7735-based LCD for real-time feedback
- Perfect for UI, debugging, and interactive applications

---

### 🌈 RGB Status Indicator
- Onboard WS2812 RGB LED
- Visual feedback for status, alerts, and animations

---

### 💾 SD Card Support
- Store data, logs, scripts, and assets
- Ideal for offline applications and dynamic content

---

### 📡 Wireless Connectivity (ESP32 Version)
- Built-in WiFi and BLE
- Network scanning, IoT communication, and remote control

---

### 🔌 USB HID & Interface Support
- Emulate keyboard/mouse (platform dependent)
- Automation and scripting capabilities

---

### ⚡ Ready for Multiple Environments
- Supports:
  - Arduino

- Easy to switch between ecosystems

---

### 🧩 Modular & Expandable Design
- Designed for future add-ons and modules
- Flexible GPIO access for custom integrations

---

### 🔋 Compact & Portable
- Small form factor
- Ideal for on-the-go development and testing

---

### 🛠 Developer-Friendly
- Open-source firmware
- Clean code structure
- Example projects included

### 🚀 Plug & Play Experience
